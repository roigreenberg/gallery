# 📸 גלריית תיק עבודות צילום (Astro + Vue 3 + Tailwind CSS)

תיק עבודות לצילום טבע, נוף, אסטרופוטוגרפיה ומאקרו.  
פרויקט מודרני, מהיר, רספונסיבי ומעוצב בערכת נושא כהה (Dark Theme), תומך RTL מלא (עברית), ומותאם לפריסה אוטומטית ב-**GitHub Pages**.

---

## 🌟 טכנולוגיות וארכיטקטורה

- **Framework**: [Astro](https://astro.build/) - מנוע Static Site Generation מהיר המפיק HTML קל משקל וטעינה מהירה.
- **UI & Interactivity**: [Vue 3](https://vuejs.org/) (`<script setup>`, Composition API) עם אינטגרציית `@astrojs/vue`.
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) - עיצוב Dark Mode אלגנטי, נקי ומינימליסטי שמבליט את הצילומים.
- **אייקונים**: [Lucide Vue Next](https://lucide.dev/)
- **מקור נתונים**: `src/data/photos.json` - מאגר נתוני צילום הכולל שמות מינים בעברית ולטינית, קטגוריות, תגיות, יחסי גובה-רוחב ונתוני EXIF מלאים.
- **פריסה**: תאימות מלאה ל-GitHub Pages (Subpath `/gallery/`) ו-Workflow ייעודי של GitHub Actions.

---

## ✨ תכונות עיקריות

### 1. דף ראשי תומך RTL מלא (`dir="rtl"`)
- גופן עברי מודרני (Assistant).
- כותרת עליונה (Header) עם לוגו, ניווט וקישור ל-GitHub.
- כותרת תחתונה (Footer) מינימליסטית עם זכויות יוצרים.

### 2. רכיב סינון וחיפוש בזמן אמת (`FilterBar.vue`)
- **כפתורי סינון (Filter Pills)**: מעבר מהיר בין קטגוריות (*הכל, טבע וציפורים, נוף, אסטרופוטוגרפיה, מאקרו*).
- **חיפוש חופשי רציף (Live Search)**: סינון מהיר לפי שם המין (עברית/לטינית), כותרת, מיקום או ציוד צילום (Sony, Canon, Nikon, אורך מוקד וכו').
- **תגיות מהירות**: סינון לפי התנהגויות ותגיות בולטות (כגון `#ציד`, `#שמי לילה`, `#Focus Stacking`).
- **מונה תוצאות דינמי**: הצגת כמות התמונות המוצגות מתוך סך התמונות, עם כפתור איפוס בלחיצה אחת.

### 3. גריד הגלריה (`GalleryGrid.vue`)
- פריסת **Masonry Grid** רספונסיבית (עמודה 1 במובייל, 2 בטאבלט, 3 במסכים רחבים) ללא חיתוך או עיוות פרופורציות.
- **טעינה עצלה (Lazy loading)** ומעבר חלק (Fade-in) בעת סיום טעינת התמונה.
- **Hover Overlay**: שכבת מידע צפה בהצבעה עם כותרת, שם מין מדעי וקטגוריה.

### 4. רכיב Lightbox לתצוגה מוגדלת (`Lightbox.vue`)
- הצגת תמונת Display ברזולוציה גבוהה.
- **ניווט מקלדת**: חצים ימינה ושמאלה למעבר בין תמונות, ומקש `Esc` לסגירה מהירה.
- **מחוות החלקה (Touch / Swipe)**: דפדוף אינטואיטיבי במסכי מגע ומכשירים ניידים.
- **Metadata Drawer (פאנל פרטים נשלף)**:
  - נתוני חשיפה וציוד (EXIF): גוף מצלמה, עדשה, אורך מוקד, צמצם, מהירות תריס, ISO, תאריך ומיקום.
  - פרטי הנושא: כותרת, שם בעברית ושם מדעי בלטינית, תיאור מלא.
  - צ'יפים לחיצים של תגיות – לחיצה על תגית סוגרת את ה-Lightbox ומסננת את הגלריה לפיה באופן מיידי.

## 🚀 הרצה והתקנה מקומית

### דרישות קדם
- **Node.js**: גרסה 18 ומעלה (נבדק בהצלחה על Node 20 ו-24)
- **npm**

### 1. התקנת תלויות
```bash
npm install
```

### 2. הרצת שרת פיתוח מקומי
```bash
npm run dev
```
ברירת המחדל תפתח שרת מקומי בכתובת: `http://localhost:4321/gallery/`

### 3. בניית גרסת פרודקשן (Production Build)
```bash
npm run build
```
התוצר הסטטי ייווצר בתיקיית `dist/`.

### 4. תצוגה מקדימה של תוצר הבנייה
```bash
npm run preview
```

## 🌐 פריסה ל-GitHub Pages

1. הגדרות כתובת האתר ב-`astro.config.mjs`:
   - ערך `site`: כתובת ה-GitHub Pages שלך (למשל `https://<YOUR-USERNAME>.github.io`)
   - ערך `base`: שם ה-Repository (למשל `/gallery`)

2. קובץ ה-Workflow האוטומטי מוכן בנתיב:
   `.github/workflows/deploy.yml`

3. בהגדרות ה-Repository ב-GitHub:
   - כנסו ל-**Settings** > **Pages**.
   - תחת **Build and deployment** בחרו ב-**Source**: `GitHub Actions`.
   - בכל `git push` לענף `main`, האתר ייבנה וייפרס אוטומטית.
